
# Two Sum

- Platform: LeetCode
- Problem Number: 1
- Difficulty: Easy
- Topic: Arrays
- Language: C++

## Problem

Find two numbers whose sum equals the target and return their indices.

## Approach 1: Brute Force

1. Use two nested loops.
2. Select the first element using i.
3. Select the second element using j.
4. Check whether nums[i] + nums[j] equals target.
5. Return the two indices if the condition is true.

### Complexity

- Time: O(n^2)
- Space: O(1)
